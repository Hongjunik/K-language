# K-language

한국어 기반 시스템 프로그래밍 언어 실험 프로젝트.

---

## ## 한 줄 소개

K-language는 한국어 기반 문법을 가진 실험용 프로그래밍 언어이며, 가능한 많은 층을 **어셈블리어(Assembly)**로 직접 구현하면서 시스템 프로그래밍의 구조와 감각을 몸으로 익히는 것을 목표로 합니다.

---

## ## 프로젝트 목적

이 프로젝트는 단순히 새로운 문법의 언어를 완성하는 것에 그치지 않고, 저수준 시스템의 동작 원리를 직접 구현하며 체험하는 데 중점을 둡니다.

1.  **한국어 기반 문법 설계**: 우리말 구조를 반영한 프로그래밍 언어 설계 경험.
2.  **저수준 시스템 구현**: 고수준 도구에 의존하지 않고 컴파일러의 핵심 단계를 직접 구현.
    * **렉서(Lexer)**: 어휘 분석기 직접 구현.
    * **파서(Parser)**: 구문 분석기 직접 구현.
    * **AST(Abstract Syntax Tree)**: 추상 구문 트리 구조 설계.
    * **코드 생성기(Code Generator)**: 대상 플랫폼의 코드 생성 로직 구현.
    * **최종 목표**: ELF 오브젝트 및 실행 파일을 직접 생성.

---

## ## 개발 철학

* 가능한 한 많은 핵심 로직을 **어셈블리어**로 직접 구현한다.
* 작지만 끝까지 이어지는 **수직 절단(Vertical Slice)** 구현 흐름을 우선시한다.
* 실행 가능한 흐름을 먼저 만든 후 구조적인 리팩토링을 진행한다.
* 장기적으로 외부 도구(NASM, ld) 없이 완전히 링크된 ELF 실행 파일을 직접 생성하는 것을 지향한다.

---

## ## 현재 개발 단계 (Phase 1 Baseline)

현재 구현은 `K_lang_v02_5` 계열이며, 어셈블리 텍스트 생성 파이프라인이 책임별 파일 분리 후에도 안정적으로 유지되는 상태를 기준선으로 삼습니다.

### ### 검증 파이프라인
`.k` 소스 파일 → **Lexer** → **Parser** → **AST** → **Code Generator** → **NASM Text** → `nasm` → `ld` → **실행**

### ### 현재 지원 기능
* **변수 제어**: 변수 선언 및 대입 (`변수 x = 7;`).
* **표준 출력**: 값 출력 기능 (`출력 x;`).
* **비교 연산**: `==`, `!=`, `>`, `<`, `>=`, `<=` 지원.
* **조건문**: `만약 (...) 이면 { ... }` 구조.
* **반복문 (While)**: `반복 (조건) 동안 { ... }` 구조.
* **반복문 (For-like)**: `반복 (초기화; 조건; 증감) { ... }` 구조 (내부적으로 `while` 구조로 Lowering 처리).

## ## K언어 문법 요약 (v0.2.5)

### 1. 값과 식별자
* **정수**: 0, 1, 7, 100 등의 숫자.
* **이름**: x, a, i 등 변수에 사용하는 식별자.

### 2. 키워드 및 기호
* **키워드**: `변수`, `출력`, `만약`, `이면`, `반복`, `동안`.
* **구분자**: 문장 끝(`;`), 소괄호(`()`), 중괄호(`{}`).

### 3. 제어문 예시
* **변수 선언**: `변수 x = 10;`
* **출력**: `출력 x + 5;`
* **조건문**: `만약 (x > 5) 이면 { 출력 1; }`
* **반복문**: `반복 (변수 i = 0; i < 3; 변수 i = i + 1) { 출력 i; }`

## ## 디렉토리 구조

* `src/include/`: 공통 정의 및 토큰/AST 정의 분리 파일 (`token_ast_defs.asm`).
* `src/main/`: 엔트리 포인트, 상태 초기화, 데이터 섹션 정의.
* `src/lexer/`: 렉서 코어 및 디버그 로직.
* `src/parser/`: 문장(Statement) 및 표현식(Expression) 파서.
* `src/ast/`: AST 생성 및 구조 디버깅.
* `src/codegen/`: 심볼 테이블 및 NASM 코드 생성 로직.
* `src/runtime/`: 실행 시 디버그 출력 보조.
* `scripts/`: 기준선 검증용 빌드 스크립트 (`build.sh`).

### 2. kompiler 드라이버 사용
최종 사용자용 명령인 kompiler를 통해 단계별 빌드가 가능합니다.

실행 파일 생성: ./kompiler path/to/file.k -o program

어셈블리만 생성: ./kompiler -S path/to/file.k (결과: .asm)

오브젝트 파일 생성: ./kompiler -c path/to/file.k (결과: .o)
